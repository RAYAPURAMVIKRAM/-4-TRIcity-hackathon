## 📌 1. Executive Summary & Problem Statement

### 🔍 The Market Gap: The $600 Billion Invisible Retail Void
Today's quick-commerce and on-demand delivery giants (Blinkit, Zepto, Swiggy Instamart) operate strictly on **digitized catalog inventory**:
- Standardized SKUs with barcodes
- Dedicated dark stores or digital POS terminals
- Structured payment gateways and pre-calculated margins

However, **over 85% of India's retail ecosystem (~$600 Billion)** is completely **unorganized and offline**:
- Roadside street vendors and wholesale produce mandis (vegetables, seasonal flowers, dry fruits)
- Hyper-specialized hardware & electronic spare parts corridors (e.g., Nakkalagutta electronics lane)
- Unlisted local street apparel shops (Old Bus Stand market stalls)
- Bureaucratic municipal counters and government token queues (tax desks, hospital OPD tokens)

None of these merchants have digital storefronts, GST billing machines, or delivery partner interfaces. For urban citizens, students, and busy professionals, running an errand to these physical locations requires hours of personal transit, haggling, and waiting in line.

```
┌───────────────────────────────────────────────────────────────────────────┐
│                    THE INDIAN COMMERCE PARADOX                           │
├─────────────────────────────────────┬─────────────────────────────────────┤
│ 🛒 Quick-Commerce (Swiggy / Blinkit)│ 🏪 ProxyGrid (Unorganized Retail)  │
├─────────────────────────────────────┼─────────────────────────────────────┤
│ ❌ Only registered digital partners │ ✅ Covers ANY physical street stall │
│ ❌ Fixed catalog SKUs only          │ ✅ Real-time inspection & haggling  │
│ ❌ 0% assistance for manual errands │ ✅ Human proxy for queues & desks   │
│ ❌ Inflated markups on products     │ ✅ Zero advance on goods + UPI QR   │
└─────────────────────────────────────┴─────────────────────────────────────┘
```

### 💡 Our Vision: Digitizing the Traditional "Joint Family" Network
In traditional Indian joint families, households never faced this friction. You always had an elder cousin, uncle, or trusted family helper living nearby whom you could call:
> *"Bhaiya, please swing by the municipal desk and check if counter 2 is open,"* or  
> *"Beta, visit the electronics lane and check if they have that ESP32 board for under ₹450."*

**ProxyGrid is the Digital Joint Family Network.** We combine an intelligent multimodal AI dispatch engine with trusted neighborhood human proxies to bridge digital intent with physical ground execution.

## 🗺️ 2. The 4 Service Tracks

ProxyGrid organizes ground concierge workflows into 4 specialized visual tracks rendered with interactive 3D glassmorphic physics:

```
┌─────────────────────────────────────────┐     ┌─────────────────────────────────────────┐
│    📍 Track 1: Ground Information       │     │   🛍️ Track 2: Custom Product Buying     │
│   • Municipal desk & token checks       │     │   • Unlisted roadside stalls & mandis   │
│   • OPD token velocity & queues         │     │   • Electronics & hardware corridors    │
│   • Signed photo proof & GPS stamps     │     │   • Smart Price Guard protection        │
└─────────────────────────────────────────┘     └─────────────────────────────────────────┘
┌─────────────────────────────────────────┐     ┌─────────────────────────────────────────┐
│    🛠️ Track 3: Skilled Handyman Work    │     │   🏍️ Track 4: Rides & Express Courier   │
│   • Vetted electricians & plumbers      │     │   • Rapid point-to-point transit        │
│   • Circuit breaker & motor diagnostics │     │   • Sanitized helmets & safety lock     │
│   • Transparent pre-repair price caps   │     │   • Zero surge price inflation          │
└─────────────────────────────────────────┘     └─────────────────────────────────────────┘
```

### 📍 1. Ground Information (Verified Physical Intelligence)
- **Use Case**: Desk verification, official notice checks, government token queue velocity, and physical document confirmations.
- **Example**: *"Visit the municipal corporation counter 2, verify if offline property tax receipts are being issued today, and take a photo of the counter notice."*
- **Deliverables**: Geotagged counter photos, timestamped field report cards, verified officer availability.
- **Fee Model**: Flat nominal dispatch fee (₹25 total). No waiting penalties.

### 🛍️ 2. Custom Product Buying (Offline Retail Proxy)
- **Use Case**: Purchasing from non-digitized roadside vendors, hardware spare-part alleys, wholesale weekly mandis, and apparel lanes.
- **Example**: *"Go to the electronics corridor in Nakkalagutta, find an ESP32 microcontroller board under ₹450, verify pin soldering, and buy it."*
- **Deliverables**: Live counter camera feed, Smart Price Guard enforcement, direct stall UPI payment pass-through.
- **Fee Model**: Zero advance on goods. Nominal ₹35–₹40 dispatch commitment. Settle actual merchant cost directly via UPI!

### 🛠️ 3. Skilled Handyman Work (Verified Local Technicians)
- **Use Case**: On-demand dispatch of trusted neighborhood electricians, plumbers, and domestic repair handymen.
- **Example**: *"Send an experienced electrician to diagnose a tripping circuit breaker in Subedari."*
- **Deliverables**: Standardized diagnostic assessment, upfront labor ceiling lock, zero-hidden-markup parts sourcing.
- **Fee Model**: Fixed transparent diagnostic fee (₹65). Replacement parts billed at verified store MRP.

### 🏍️ 4. Rides & Express Delivery (Direct City Mobility)
- **Use Case**: Immediate two-wheeler city transit and urgent point-to-point package/document movement.
- **Example**: *"Need an immediate bike ride from Hanamkonda Chowrasta to Kazipet Railway Station platform 1 entrance."*
- **Deliverables**: Direct-route transit with verified proxy rider, sanitized safety helmet, live GPS route telemetry.
- **Fee Model**: Fixed city transit rate (₹45 base). Strictly zero surge pricing.

## 🧠 3. AI Architecture & Gemini Integration

ProxyGrid does not treat **Google Gemini 1.5 Flash** as an arbitrary chat wrapper. Instead, Gemini acts as the **Autonomous Task Dispatcher and Compliance Kernel** operating across three distinct pipeline stages:

```
                          [ User Input (Messy Speech / Text) ]
                                          │
                                          ▼
                      ┌───────────────────────────────────────┐
                      │    ROLE 1: SAFETY & LEGAL GUARDRAIL   │
                      │  • Weapon / Contraband / Bribe Check  │
                      │  • Immediate Refusal on Violation     │
                      └──────────────────┬────────────────────┘
                                         │ Passed
                                         ▼
                      ┌───────────────────────────────────────┐
                      │     ROLE 2: SMART INTENT DECOMPOSER   │
                      │  • Task Parameter & Target Extraction │
                      │  • Geotarget Landmark Resolution      │
                      │  • Deliverable Checklist Formulation  │
                      └──────────────────┬────────────────────┘
                                         │ Structured Contract
                                         ▼
                      ┌───────────────────────────────────────┐
                      │    ROLE 3: SMART BUDGET PRICING ENGINE│
                      │  • Smart Price Guard Ceiling Lock     │
                      │  • Zero Waiting Penalty Policy        │
                      │  • ₹0 Upfront Goods / UPI Settlement  │
                      └──────────────────┬────────────────────┘
                                         │
                                         ▼
                      [ Interactive Smart Contract Card in Chat ]
```

### 🛡️ Role 1: Safety & Legal Guardrails
Every incoming prompt is evaluated against rigorous ethical and legal filters:
- **Prohibited Errand Detection**: Detects weapons, narcotics, stolen property, bribery, illegal desk tampering, and impersonation.
- **Immediate Rejection Protocol**: Returns a strict security alert:  
  `🚨 [UNSAFE REQUEST] For the safety of our partners, we cannot process this request.`  
  Halts execution with zero platform or cancellation charges.

### 🧩 Role 2: Natural Language Intent Parsing & Decomposition
Translates messy, unstructured conversational language into typed, actionable **Task Contracts**:
- Extracts target geographic coordinates (e.g., Nakkalagutta electronics corridor, MGM Hospital OPD).
- Identifies critical physical deliverables (e.g., Geotagged Stall Photo, Pin Inspection, Token Slip Number).
- Specifies task completion criteria and geofence boundary radii (typically 50m).

### 💰 Role 3: Smart Budget Pricing Engine
Engineered specifically for the realities of Indian street commerce:
1. **Zero Advance on Goods**: Customers never deposit estimated merchandise funds into a platform wallet. Product costs are **₹0 upfront**.
2. **Nominal Upfront Dispatch Commitment**: The user pays only a nominal ₹35–₹40 fee (Base Partner Fee: ₹20, Distance: ₹15, Platform Fee: ₹5) to mobilize the proxy.
3. **Strict Zero Waiting Fee Policy**: Unlike ride-hailing and food apps that punish customers for delays, ProxyGrid charges ₹0 waiting fees for street stall lines.
4. **Smart Price Guard**: If the vendor quotes an amount exceeding the user's defined ceiling, the proxy cannot proceed without explicit real-time customer re-authorization.
5. **Direct Stall UPI Settlement**: The proxy transmits the stall's BharatQR/UPI ID directly to the user's screen for 100% transparent peer-to-peer settlement.

### ⚡ Deterministic Zero-Crash Fallback System
To ensure flawless operation even under spotty network connections or Gemini API rate limits, ProxyGrid integrates an **embedded deterministic rule-engine fallback**:
- Regex-driven semantic pattern matching for local landmark entities and price caps.
- 100% resilient offline capability with identical typed contract output.
- Zero client-side crashes under any runtime contingency.

## 🚀 6. Local Development Setup

Follow these instructions to run ProxyGrid locally on your development machine:

### Prerequisites
- **Node.js**: v18.17.0 or higher (Node 20+ recommended)
- **Package Manager**: npm or yarn
- **Git**: Installed and configured

### Step-by-Step Installation

```bash
# 1. Clone the repository
git clone https://github.com/RAYAPURAMVIKRAM/-4-TRIcity-hackathon.git

# 2. Navigate to project root
cd -4-TRIcity-hackathon

# 3. Install dependencies
npm install

# 4. Configure environment variables
# Create a .env.local file in the root directory
echo "NEXT_PUBLIC_GEMINI_API_KEY=your_gemini_api_key_here" > .env.local

# 5. Start the development server with Turbopack
npm run dev
```

### Verification
Open your browser and navigate to:
```
http://localhost:3000
```
- Click any of the 4 track cards to trigger the floating dispatch widget.
- Try entering custom prompts like:
  - `"Go to electronics lane in Nakkalagutta, find ESP32 board under ₹450"`
  - `"Check queue length at GWMC municipal office counter 2"`
- Test the built-in safety guardrail by asking for restricted or hazardous tasks.
